VENTAPE - REVISION DE INTERFAZ MOVIL Y CONFIGURACION
Fecha: 13/11/2026

Cambios realizados:
1. El panel Documento de venta ahora aparece antes del listado de productos en pantallas móviles. En escritorio conserva la distribución de dos columnas.
2. La burbuja Escanear QR tiene mayor contraste, tamaño, borde y prioridad visual.
3. Se movió el componente de sección Sec fuera del componente Cfg. Antes se declaraba dentro de Cfg y se recreaba en cada render; eso podía desmontar los campos y provocar pérdida del foco mientras se escribía. Ahora mantiene identidad estable para permitir escribir de corrido.

Se conserva la funcionalidad de WhatsApp sin cambios.
No se modificó el backend ni las políticas de Supabase.


AJUSTE ADICIONAL 13/11/2026:
- La plantilla de cotización/documento ahora presenta los términos y condiciones en líneas separadas. Detecta tanto saltos de línea como numeración (01., 02., 03.) aunque el texto venga pegado en un solo párrafo.
- La vigencia y la nota de stock se muestran en una línea independiente.


AJUSTE ADICIONAL — PDF Y WHATSAPP DESDE CELULAR:
- La captura del documento para PDF se realiza sobre un lienzo fijo de 794 px (A4), independiente del ancho de pantalla del celular.
- El PDF se pagina en hojas A4 sin estirar el documento verticalmente.
- El botón del visor ahora prepara y comparte el archivo PDF mediante Web Share API cuando el navegador permite compartir archivos.
- Si el navegador no permite adjuntar archivos mediante compartir, descarga el PDF y abre el chat de WhatsApp con el mensaje; en ese caso el usuario debe adjuntar el PDF descargado.
- En el listado de documentos, el acceso WhatsApp abre el visor PDF para usar la opción de compartir archivo.
- No se modificó el esquema, las tablas, las políticas ni los datos de Supabase.
